# M1 — Mate in One Studio

Run `npm install`, then `npm run dev`. Open http://127.0.0.1:5188. `npm run build` makes a static deployment in `dist`. Serve it over HTTP; Web Workers cannot run from a file:// page.

Original Lichess brown board and cburnett SVG assets are bundled. Google Sans is bundled from the Google Fonts stylesheet. Stockfish.js 19.0.0 Lite single-threaded WASM runs locally, with no cross-origin isolation requirement. Engine binaries are the unmodified `stockfish` npm release. Upstream source: https://github.com/nmrugg/stockfish.js/tree/v19.0.0. GPLv3 license is in public/engine/LICENSE.txt. Lichess asset attribution and license information are in public/LICHESS-COPYING.md; pieces are GPLv2+ and board AGPLv3+. App source is available under GPLv3; redistributed Lichess board retains its AGPLv3+ terms.

The generator creates compositions, not positions sourced from played games. It rejects either king initially in check, adjacent kings, illegal pawn ranks, and positions with more than one legal mating move. Stockfish confirms the unique solution at depth 3. Pawn promotion is supported, including underpromotion. Slider bands progressively raise a structural difficulty score based on material, competing checks and mating piece. Estimated Elo is not an empirically calibrated rating. The M1/M2 slider chooses mate in one or mate in two. M2 generation uses Stockfish as a candidate filter, then exhaustively checks all legal first moves and every defensive reply. Exactly one first move must force mate in two, with no immediate mate available. The app animates a defensive reply before the player makes the final mating move. Wrong first moves show a legal refutation that prevents mate on the next turn.

Previously generated FENs, settings and session progress persist in localStorage. Clear browser storage to reset. There is no backend or account. Generation runs in a separate worker to keep dragging and the UI responsive. Motion obeys the operating system's reduced-motion preference and can be disabled. Pieces lift immediately on pointer-down, follow the cursor with spring sway, and animate onto the drop square. Incorrect moves glide back to their origin. Mouse, touch and keyboard selection are supported.
